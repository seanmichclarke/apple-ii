# apple-ii — "Applesoft's Loaded Dice" research workspace

Research, review, source listings and deliverables supporting Jeff Robison's
VCF Midwest 21 (2026) talk *Applesoft's Loaded Dice — The Truth About Randomness
on the Apple II, Then and Now*.

- `BRIEF.md` — project brief
- `deck/` — original deck (`.pptx`) and extracted XML
- `deliverables/` — edited deck, slide assets, fact sheet, Q&A prep, open items, evidence
- `woz/` — design intent & attribution (Integer BASIC vs Microsoft's Applesoft RND)
- `research/` — literature and statistical tools
- `review/` — technical/narrative reviews and experiment evidence
- `source/` — annotated ROM listings, demos, provenance
- `slides/` — outline

Python tools expect a local venv (`python3 -m venv .venv`); it is not committed.
